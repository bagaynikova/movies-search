# Что посмотреть? 🍿

Веб-приложение на Python и Streamlit для поиска фильмов, построения рейтингов и анализа каталога.

## Возможности

### Поиск фильмов
- поиск по названию (без учета регистра);
- фильтрация по жанру, стране производства и языку оригинала;
- фильтрация по диапазону годов выпуска, рейтингу и продолжительности;
- сортировка результатов по рейтингу, популярности, количеству голосов или году выпуска;
- просмотр краткой информации о фильме и описания, если оно присутствует в данных;
- выгрузка найденных фильмов в CSV.

### Рейтинг
- построение списка из 10, 20 или 50 фильмов;
- критерии сортировки: взвешенный рейтинг, средняя оценка, популярность или количество голосов;
- фильтр по жанру и минимальному количеству голосов;
- экспорт рейтинга в CSV.

Взвешенный рейтинг рассчитывается по формуле:

`WR = (v / (v + m)) * R + (m / (v + m)) * C`

где:
- `R` — средняя оценка фильма;
- `v` — количество голосов за фильм;
- `C` — средняя оценка по каталогу;
- `m` — минимальный порог количества голосов.

Формула снижает влияние фильмов с небольшим числом оценок: их итоговая оценка сильнее приближается к средней оценке каталога.

### Аналитика
- средняя оценка фильмов;
- медианная продолжительность;
- количество стран производства;
- распределение оценок;
- средняя оценка по годам.

## Стек технологий

- **Python 3.11** — язык разработки;
- **Streamlit** — веб-интерфейс;
- **Pandas** — чтение, очистка, преобразование и фильтрация данных;
- **Altair и встроенные графики Streamlit** — визуализация;
- **CSV** — формат исходного набора данных и экспорта результатов;
- **Docker** — контейнеризация;
- **Pytest** — автоматизированные тесты;
- **Ruff** — проверка качества кода.

## Запуск локально

Требуется Python 3.11 или совместимая версия и Git.

1. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone https://github.com/bagaynikova/movies-search.git
   cd movies-search
   ```

2. Создайте виртуальное окружение:

   **Windows (PowerShell):**
   ```powershell
   py -3.11 -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

   **Linux / macOS:**
   ```bash
   python3.11 -m venv .venv
   source .venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. Запустите приложение:

   ```bash
   streamlit run app.py
   ```

5. Откройте адрес, который Streamlit выведет в терминале (обычно `http://localhost:8501`).

## Запуск через Docker

Для запуска через Docker не требуется устанавливать Python-зависимости на хост-компьютер. Нужен установленный и запущенный Docker.

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/bagaynikova/movies-search.git
   cd movies-search
   ```

2. Соберите Docker-образ из `Dockerfile`:

   ```bash
   docker build -t movies-search .
   ```

3. Запустите контейнер:

   ```bash
   docker run --name movies-search-app --rm -p 8501:8501 movies-search
   ```

4. Откройте приложение в браузере:

   **http://localhost:8501**

5. Чтобы остановить приложение, нажмите `Ctrl+C` в терминале, где запущен контейнер.

Если порт `8501` уже занят, можно назначить другой порт компьютера, например:

```bash
docker run --name movies-search-app --rm -p 8502:8501 movies-search
```

В этом случае приложение будет доступно по адресу `http://localhost:8502`.

### Что делает Dockerfile

- использует базовый образ `python:3.11-slim`;
- устанавливает зависимости из `requirements.txt`;
- копирует приложение, папки `utils` и `data` в контейнер;
- запускает процесс от отдельного непривилегированного пользователя;
- открывает порт `8501`;
- содержит проверку доступности Streamlit и команду запуска приложения.

## Запуск тестов

Установите зависимости проекта, затем выполните из корневой папки:

```bash
python -m pytest -q
```

Тесты проверяют разбор списков жанров и стран, обработку пустых и некорректных значений, фильтрацию по параметрам и корректность расчёта взвешенной оценки.

Для проверки стиля кода:

```bash
ruff check .
```

## Данные

Приложение загружает каталог из `data/movies.csv`. При чтении проверяется наличие обязательных полей, очищаются записи без названия, преобразуются числовые значения, разбираются списки жанров и стран, определяется год выпуска и удаляются дубликаты по идентификатору, если он присутствует.

В текущей реализации в каталог приложения попадают записи с годом выпуска от 1874 до 2017 включительно.
